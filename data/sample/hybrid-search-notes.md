# 混合检索笔记

混合检索让向量路与 BM25 关键词路并行召回、融合排序：向量语义泛化但精确词面易漂移，BM25 词面精准但不理解同义改写，两路互补是生产级 RAG 的默认选择。

## 两路召回与 RRF 融合公式

向量路：查询向量化后与块向量算余弦相似度取 Top-K；关键词路：BM25 基于倒排索引打分（k1≈1.2、b≈0.75），中文按 bigram+单字分词。两路分数量纲不同，不能直接相加，标准做法是 **RRF（Reciprocal Rank Fusion）倒数排名融合**：`score(d) = Σ w_i / (k + rank_i(d))`。`rank_i(d)` 是文档 d 在第 i 路的名次，k 取 60 平滑头部名次差异，w_i 为各路权重（关键词 0.6 / 向量 0.4 是常见起点）。RRF 只用名次不用分数，天然规避量纲问题。

## 何时关键词路比向量路更可靠

**专有名词与型号**：如 `text-embedding-v4`，嵌入易漂到语义近邻，BM25 精确命中完整词面；**错误码与数字串**：`ERR_4021`、`HTTP 429` 在向量空间几乎无区分度；**代码标识符**：`chunk_document`、`/api/rag/build`，符号切分后词面唯一。实践：排障与报错码检索调高关键词权重或直接 keyword 模式；自然语言问法保持向量主导。
